# Workshop-data alternatives

Checked on 29 August 2026. This preserves evidence-backed options for later selection; none is
complete enough to support real-world safety, insurance, or operational decisions.

| Candidate | Source / owner / format | Reuse status | Query fit and teaching scenario | Sensitivity | Why it is not the current default | Next verification step |

The label is retained only so the team can return to the lead. | Obtain the original official URL and confirm owner, licence, fields, download route, and sensitivity before reconsidering it. |

## Recommendation

Use `victoria-road-crash-sample.json` for the current Gather → Extract → Analyse path: it maps
directly to the agreed date-and-keyword exercise. For a workplace or insurance story, the verified
WorkSafe Victoria workbook is the best next candidate, but only after deliberately changing the
lesson to aggregate claim observations. Do not silently mix crash records and claim-count data.
