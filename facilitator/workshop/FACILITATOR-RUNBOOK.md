# Facilitator runbook

Before the room: run the corpus generator check, `dotnet test`, deterministic Gather debug checks, then `ready --prompt "Show up to 5 intersection crashes from 2012."` with the actual presenter model loaded.

The deterministic checks do not prove model compatibility. If readiness fails, use saved Gather output, demonstrate code gates, and do not claim a live model rehearsal.

After five minutes of setup, move a participant to pairing or saved output. Gather is ordinary C# over one approved crash sample. Extract and Analyse are separate tool-free typed calls; code validates IDs, shape and confidence before analysis. The scenario supports an insurance/safety analyst and never automates a claim decision.
