# Organiser pack

**Small Models, Sharp Jobs: Build a Local Agent That Proves Its Work** is an 85-minute hybrid build-along. Participants build or follow a .NET workflow that filters an approved Victorian crash corpus, selects relevant records through a typed model call, analyses only validated compact evidence, and shows code-owned confidence and validity gates. The simulation assists an insurance/safety analyst; it does not decide claims.

Local model setup is optional for observers; pairing and saved checkpoints are the recovery route. See `AGENDA-85.md` and `FACILITATOR-RUNBOOK.md`.
