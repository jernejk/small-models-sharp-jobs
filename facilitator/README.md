# Facilitator material

This directory is intentionally separate from the attendee learning path in [`../workshop/`](../workshop/).
It contains delivery material, research and evidence, recovery resources, the HTML slide deck, and
the finished reference solution.

- [`workshop/slides/`](workshop/slides/) — presenter deck and assets
- [`workshop/FACILITATOR-RUNBOOK.md`](workshop/FACILITATOR-RUNBOOK.md) — delivery runbook
- [`workshop/reviews/`](workshop/reviews/) — model, compatibility, and review evidence
- [`workshop/reference-run/`](workshop/reference-run/) — saved recovery outputs
- [`reference/solution/`](reference/solution/) — working full-pipeline recovery reference
- [`archive/`](archive/) — retired facilitator research only; never an attendee entry point

These materials are not a second attendee starter project.
