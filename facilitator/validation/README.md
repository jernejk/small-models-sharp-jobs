# Validation ledger

Run each project without a model first. Model-backed stages are then checked against the currently
loaded local 4B model; never record credentials in this directory.

The expected distinction is deliberate: labs 01, 02, 04 and 05 are exercise scaffolds until the
attendee completes their focused TODO, and 03 is one too — its `query` needs the model, while its
`gather --term` debug check does not; 06 is the completed
end-to-end reference.
